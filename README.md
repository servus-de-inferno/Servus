# Servus

Первый прототип простого 3D-шутера от первого лица. Unity 6000.6.5f1, встроенный рендерер (Built-in).

## Запуск

1. В Unity Hub выбери **Add → Add project from disk** и папку `Servus` с этим файлом.
2. Открой проект в Unity 6000.6.5f1 и дождись компиляции.
3. При первом открытии тестовая сцена создаётся автоматически. Если этого не произошло, выбери меню **Servus → Create prototype arena**.
4. Открой `Assets/Scenes/Prototype.unity`, нажми **Play** и щёлкни внутри окна **Game**.

## Управление

WASD — движение; мышь — обзор; левый Shift — бег; Space — прыжок; R — возврат на старт; Esc — освобождение курсора. Щелчок мышью возвращает управление.

На арене есть стены, укрытие, ступени и платформа для проверки прыжков. Диагональное движение не увеличивает скорость. Игрок сталкивается со стенами и потолком; при падении за пределы карты возвращается на старт.

Параметры скорости, прыжка и чувствительности мыши находятся на объекте Player в компоненте First Person Motor. Пока нет стрельбы, врагов и звука.

Используется встроенный Input Manager. В **Edit → Project Settings → Player → Other Settings → Active Input Handling** должно быть **Input Manager (Old)** или **Both**.

## GitHub

Создай пустой публичный репозиторий `Servus` в аккаунте `servus-de-inferno`. Добавляй в Git папки Assets (включая .meta), Packages, ProjectSettings, а также README.md и .gitignore. Library и Temp добавлять не нужно.

## Основа движения

Контроллер использует [Unity CharacterController.Move](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/charactercontroller/move). Гравитация рассчитывается отдельно в FirstPersonMotor.

## Проверка

Оба C#-скрипта скомпилированы без ошибок отдельным компилятором из установленной Unity с её библиотеками. Проверка в Play Mode пока не выполнена: фоновый запуск редактора остановился на инициализации лицензии. Если Unity не открывается, войди в Unity Hub и проверь активную лицензию в настройках Hub.

После открытия проверь движение вперёд и по диагонали, столкновение со стенами, прыжок на платформу, бег, освобождение курсора и возврат на старт клавишей R.
